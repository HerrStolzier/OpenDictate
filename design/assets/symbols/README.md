# Symbole

Pixelsymbole im 12 × 12-Raster, gezeigt in 36 px (3 px je Zelle). Feste Farben aus dem Nacht-Theme; in Code lieber die Komponenten `PixelIcon` und `Keycap` nehmen, die mit dem Theme wechseln.

- `icon-rec.svg`: Aufnahme, in `#FF5D5D` (rec).
- `icon-check.svg`: Eingefügt, in `#B6FF4D` (signal).
- `icon-error.svg`: Fehler, in `#FF5D5D` (rec).
- `icon-prompt.svg`: Eingabezeichen „›“, in `#B6FF4D` (signal).
- `icon-key-option.svg`, `icon-key-shift.svg`, `icon-key-space.svg`: Tastensymbole ⌥ ⇧ Leertaste in `#E9EEE2` (ink), für dunkle Tastenkappen.
