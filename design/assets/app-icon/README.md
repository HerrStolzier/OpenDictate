# App-Icon

- `app-icon-1024.png`, `app-icon-512.png`, `app-icon-256.png`: macOS-App-Icon auf transparentem Grund. Die dunkle Fläche (824 × 824 px bei 1024) hat macOS-Form, Rand, leise Bildschirmzeilen und Schatten bereits eingebaut. Darauf das Eingabezeichen „›“ in Geist Pixel und Blink mit grünem Leuchten.

Für die App die `.icns`-Datei aus `app-icon-1024.png` erzeugen (iconutil). Unter 32 px Blink nicht verkleinern, sondern `blink-32.svg` oder `blink-16.svg` aus den Logos nehmen.
