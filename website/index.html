Mit lokalem Modell

Deine Stimme bleibt bei dir.

Mit einem lokalen Modell erkennt dein eigenes Gerät, was du sagst. Weder deine Aufnahme noch dein Text verlassen es. Dafür brauchst du keinen Schlüssel und kein Konto. So richtest du es ein

Mit OpenAI geht die Aufnahme direkt von deinem Gerät dorthin, mit deinem eigenen Schlüssel. Ich sehe davon nichts, und die App zählt nicht mit. Der Code liegt offen auf GitHub.

So geht's

Blink macht es dir vor.

  1. 01So diktierst du

    Taste halten, sprechen, loslassen. Dein Text steht da, wo dein Cursor ist: in der Mail, im Chat oder im Dokument.

  2. 02Gleich auf Englisch

    Du sprichst Deutsch, eingefügt wird Englisch oder eine von elf weiteren Sprachen. Für die Mail ins Ausland oder den Gaming-Chat. Das eingebaute Diktat vom Mac übersetzt nicht.

  3. 03Nichts geht verloren

    Bricht das Netz weg oder hakt der Dienst, bleibt deine Aufnahme auf deinem Rechner. Mit „Nochmal senden“ schickst du sie los, bis zu 24 Stunden lang.

  4. 04Kostenlos mit eigenem Server

    Trag einen Server auf deinem Rechner ein. Dann kostet ein Diktat nichts, und die Aufnahme bleibt bei dir.

  5. 05Erste Schritte am Mac

    App laden, in die Programme ziehen, Schlüssel oder Server eintragen, Kürzel wählen. Dann geht es los.
