Übersetzen

Sprich Deutsch, schreib Englisch.

OpenDictate übersetzt, bevor es einfügt. Die Mail ins Ausland oder die Nachricht im Gaming-Chat schreibst du so auf Englisch oder in einer von elf weiteren Sprachen.

Und das eingebaute Diktat vom Mac? Das übersetzt nicht, und eine verpatzte Aufnahme kannst du dort nicht noch einmal senden.

Datenschutz

Was mit deiner Aufnahme passiert.

Mit OpenAI geht sie direkt von deinem Rechner dorthin, mit deinem eigenen Schlüssel. Mit einem lokalen Modell verlässt sie den Rechner nicht. Ich sehe davon nichts, und die App zählt nicht mit. Der Code liegt offen auf GitHub.

Probier es aus.
