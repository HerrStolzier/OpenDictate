Am selben Abend mit Bastis Go: whisper.cpp 1.9.5 über Homebrew, Modell
`ggml-large-v3-turbo-q5_0.bin` (SHA-256 `394221709cd5…ffa7e2`, wie von

| Prüfpunkt | Ergebnis |

| Auffälligkeit | Bei Sprechpausen setzt whisper.cpp zwischen den Segmenten Zeilenumbrüche; im Text erschienen Absätze. Nachgestellt mit einer Probe mit zwei Pausen. Behoben nach Build 11 (Umbrüche werden bei eigenem Server zu Leerzeichen). |

## Grenzen

- Einzelne Diktate sind kein Qualitätsnachweis. Beim eigenen Server ist nur
  Transkription über whisper.cpp auf diesem Mac belegt (oben); Übersetzung über
  einen eigenen Server, andere Server und die offenen Fälle der Diktatanzeige
  sind nicht live geprüft. Sie stehen in
  [remaining-acceptance](../../remaining-acceptance.md#macos).
- Nichts ist veröffentlicht.
