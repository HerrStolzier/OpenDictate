Quellrevision. Sie verändert keine installierte App und verwendet keine
Schlüsselbundwerte:

```bash
(

  cee6fcc5d7c2bc311eacbad82f1e6e7538148d1c8808fd61b18b598a0b199a82
unzip -tq "$ARCHIVE"
CHECK_DIR="$(mktemp -d)"

git show b786d4ccd75462b902d3a1439c247bd1a5aeeca8:scripts/verify-app.sh > "$CHECK_DIR/verify-app.sh"
ditto -x -k "$ARCHIVE" "$CHECK_DIR"
bash "$CHECK_DIR/verify-app.sh" --release --team-id K5AF446C3N "$CHECK_DIR/OpenDictate.app"
)
```
